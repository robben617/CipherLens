## Rating Method Description

### Rating Process（逐项独立验证）

1. **Extract Single Result Item**：从 knip JSON 输出中逐条提取文件、导出、类型；设计令牌与后端模块由补充脚本提取。
2. **Reference Verification**：对每一项用 Grep 搜索 `src/**/*.{ts,vue}`，必要时补查 `e2e/`；对文件额外检查 router 与所有 import；对令牌检查 `var()`、`setProperty()`、Vue style 键三种引用方式。
3. **Result Analysis**：按「完全无引用 / 仅模块内引用 / 引用不可达」三类定级。
4. **Record Basis**：每项记录搜索关键词、匹配数、结论与依据。

### Rating Criteria

| Rating Criteria | High Confidence | Medium Confidence | Low Confidence |
| --------------- | --------------- | ----------------- | -------------- |
| Number of References | 0，或唯一引用不可达 | 仅本模块内部引用 | 多处显式引用 |
| File Existence | 存在但无引用 | 存在且有失效引用 | 不存在或路径错误 |
| Usage Scenario | 完全未使用 | 内部使用 / 待产品确认 | 运行时真实使用 |
| Recommended Action | 可删除 | 收窄导出或确认后删除 | 保留 |

### Search Strategy

- **Files**：文件名、组件名、`DiagnosisCard` / `c-diagslot` / `c-annotation`。

- **Search Scope**：`src/**/*.{ts,vue}` 为主，`e2e/**/*.ts` 为辅；后端使用 AST 模块可达性分析。
