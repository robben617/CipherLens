## 1. 系统 reduce 与页内开关

| 场景 | `data-motion` | 动效按钮 | running animations |
|---|---|---|---|
| 系统 `prefers-reduced-motion: reduce` | `reduced` | `aria-pressed=true`，标签“恢复动效” | 0 |
| 系统 no-preference | `""` | `aria-pressed=false`，标签“减少动效” | 0 |
| 页内点“动效”后 | `reduced` | `aria-pressed=true` | 0 |

`useReducedMotion` 在初始化时读取系统媒体查询；页内按钮切换同一个布尔，并立即 `document.getAnimations().forEach(a => a.cancel())`。

## 2. 静态信息补偿

系统 reduce 下逐步切换，矩阵不再播放动画，改为常驻静态线索：

| 操作 | 变化格 | 角标 | 文本线索 | 动画 |
|---|---|---|---|---|
| SubBytes | 16 | 16 个 `is-changed`，右上 `tr` 角标 | 无 | 0 |
| ShiftRows | 12 | 12 个 `is-changed` | `←1` / `←2` / `←3`（按行） | 0 |
| MixColumns | 16 | 16 个 `is-changed` | `MIX` | 0 |
| AddRoundKey | 16 | 16 个 `is-changed` | `⊕` 上标，16 格 `is-cue-xor` | 0 |

ShiftRows 的 4 个未变化格（第 0 行）没有角标；其余 12 格有角标并按行显示位移量。

## 3. 动画归零

| 检查点 | `document.getAnimations().length` |
|---|---|
| 系统 reduce 初始 | 0 |
| ShiftRows | 0 |
| SubBytes | 0 |
| MixColumns | 0 |
| AddRoundKey | 0 |
| 页内开关开启 | 0 |

三段归零已落地：

1. `--d-1…--d-4` / `--d-linger` / `--d-fade-linger` 在 reduced 块中置 `0.01ms`；
2. 所有 WAAPI 动画在 `reduced` 时直接不创建；
3. `useReducedMotion` 开启时 `getAnimations().forEach(cancel)`。

## 4. 灰度断言

对 `.c-matrix` 加 `filter: grayscale(1)`，在第 1 轮 ShiftRows（12 格变化 / 4 格不变）采样：

| 项 | 实测 |
|---|---|
| 变化格数量 | 12 |
| 未变化格数量 | 4 |
| 变化格平均亮度 | 195.37 |
| 未变化格平均亮度 | 242.61 |
| 亮度差 | **47.24** |
| 手册阈值 | ≥14 |
| 结果 | 通过 |

> 与手册的偏差：手册写 `e2e/grayscale.spec.ts`，但项目当前没有 Playwright/e2e 框架。本轮用既有的 Chrome CDP pipe 通道执行了同等的真实像素断言（脚本在 `output/cdp-f14.mjs`，不入库）；没有为了一个断言引入 Playwright。若后续需要 CI 化，再把该脚本收成正式 e2e spec。
