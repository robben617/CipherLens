## 6. 实现口径

| 项 | 实现 |
|---|---|
| 常驻槽位 | `.c-diagslot` 高度锁 `var(--diag-row-h)`（常规 40 / 演示 56），空态显示 `DIAGNOSTIC —` |
| 位置 | 只在 E 区顶部；`overflow` 可见仅用于左侧 12×2px 刻痕，不进 C/D |
| 单条约束 | `note` 单值；已有批注时 `fire()` 直接拒绝（`lastBlocked='visible'`） |
| 间隔 | `lastFiredAt` + 45s 冷却 |
| 通道闸门 | `ready()` 与 `fire()` 都检查 `activeChannel === 'idle'` |
| 空闲规则 | `lastActivityAt`，20s |
| 来回规则 | 最近 7 次翻步完全交替、窗口 ≤2 步、每段停留 <3s → `pendingType='toggle'` |
| 折线 | SVG path，`pathLength=100` + `stroke-dashoffset` 三段（140/160/120ms，总 420ms） |
| 刻痕 | 由 `--tick-y` 驱动，JS 取目标格中心 − 槽位顶，不改 `top` 内联值 |
| 关闭 | × 或作答 → 200ms opacity 淡出，不做退场位移 |
| 焦点 | 不自动聚焦、不移动焦点、无 toast、不居中 |
| reduced-motion | 不创建折线动画，折线直接显示完整；目标格不播描边动画 |
| 调试入口 | `?debug=diagnosis` → `window.__diag.forceFire(type)`；另暴露 `state/setChannel/reset/dismiss` 供验收 |

## 8. 已知边界

| 项 | 说明 |
|---|---|
| 诊断历史与时间轴标记 | F18 只记录 `history`；Timeline 现有标记仍是 F12 的演示数据，按计划由 W4 改为 `useDiagnosisStore.history` 驱动 |
| 批注状态 | 只实现 `expanded` 与作答后关闭；`collapsed`（手动收起为一行）未做，手册 F18 未要求 |
| 作答 | 是 / 不是 / 这提示不对只记录点击并关闭，不做后续规则学习或落库 |
| 自动规则 | 批注需在 20s 空闲后出现；手动关闭后受 45s 冷却约束，不会立刻再出 |
| 目标字节 | 取当前步 `changed` 的第 1 个（来回规则取第 8 个）；当前步无变化时退回 index 0 |
| `?debug=diagnosis` | 验收临时入口，含 `setChannel/reset` 测试方法，按临时设施对待、不持久化 |
| 真实用户行为 | 规则只在本前端内存中运行，不发请求、不写数据库；诊断上报留待 W3/W4 埋点链路 |
| 折线跨区 | 折线/刻痕只在 E 区左边界内，不进入 C 区；指向矩阵靠目标格红线描边与刻痕 y 对齐共同表达 |
