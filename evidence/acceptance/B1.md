## 1. FIPS-197 C.1 向量

启动：

```bash
cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

请求：

```bash
curl -s -X POST http://127.0.0.1:8000/api/aes/trace \
  -H "Content-Type: application/json" \
  -d '{"plaintext_hex":"00112233445566778899aabbccddeeff","key_hex":"000102030405060708090a0b0c0d0e0f","key_bits":128,"direction":"encrypt"}'
```

响应关键字段：

| 字段 | 实测 |
|---|---|
| `trace_id` | `t_b8f9cffc` |
| `ciphertext` | `69c4e0d86a7b0430d8cdb78070b4c55a` |
| `key_bits` | `128` |
| `direction` | `encrypt` |
| `rounds` | `10` |
| `step_count` | `40` |
| `key_schedule` 词数 | 44 |
| `steps[0].op` | `add_round_key`，round 0 |
| `steps[39].op` | `add_round_key`，round 10 |

## 2. 后端 vs 前端 engine 逐字段对比

脚本：`backend/tools/compare_trace.py`。它把前端 `engine/trace.ts` 用 esbuild 打包后在 Node 中运行，再与后端 `build_trace` 逐字段比较。

输出：

```text
frontend_steps=40
backend_steps=40
frontend_ciphertext=69c4e0d86a7b0430d8cdb78070b4c55a
backend_ciphertext=69c4e0d86a7b0430d8cdb78070b4c55a
frontend_trace_id=t_b8f9cffc
backend_trace_id=t_b8f9cffc
differences=0
```

比较字段：`trace_id`、`ciphertext`、`key_bits`、`direction`、`rounds`、`step_count`、`key_schedule`，以及每个 step 的 `index/round/op/state_before/state_after/changed/key_indices/key_words/label`。

> 唯一有意差异：`meta.source` 前端为 `local-engine`、后端为 `backend`；字段形状一致，对比脚本忽略该值。

## 4. 非法入参

短 key（30 hex）：

```json
{"error":{"code":"validation_error","message":"String should have at least 32 characters","field":"key"}}
```

key_bits 与 key 长度不匹配（192 位 key 声明 128）：

```json
{"error":{"code":"invalid_key_bits","message":"key_bits 128 does not match key length 192","field":"key"}}
```

两者均为 HTTP 400，符合 `{error:{code,message,field}}`。

## 7. 实现口径

| 项 | 实现 |
|---|---|
| 接口路径 | `POST /api/aes/trace` |
| 请求字段 | `plaintext_hex` / `key_hex` / `key_bits` / `direction`（以 §11.2 为准） |
| 响应字段 | 与前端 `engine/trace.ts` 同构，额外保留 `ciphertext` / `meta` |
| 字节表示 | `state_before` / `state_after` 为 0..255 整数数组，列优先 |
| hex | 小写、无 `0x`、无空格 |
| trace_id | 与前端相同的 FNV-1a 32 位内容哈希 |
| 算法 | Python 重写 FIPS-197，不引入加密库 |
| 错误 | `{error:{code,message,field}}`；Pydantic 校验错误统一映射为 400 |
| 数据库 | 手写 `sqlite3`，无 ORM |

## 8. 已知边界

| 项 | 说明 |
|---|---|
| `direction: decrypt` | B1 只实现加密 trace；解密返回 400 `unsupported_direction`。契约允许 decrypt，但前端 engine 目前也只支持 encrypt，解密 trace 留到反向单步/解密功能点 |
| `meta.source` | 后端为 `backend`，前端为 `local-engine` |
| 依赖 | 本机已安装 FastAPI 0.141.1 / uvicorn 0.52.4 / pydantic 2.13.4；`requirements.txt` 已锁版本，未创建 venv |
| 数据库内容 | 表已建、无数据；user/session 写入在后续功能点 |
| 后端测试框架 | 未引入 pytest；本轮用 curl + 跨语言对比脚本验证 |
