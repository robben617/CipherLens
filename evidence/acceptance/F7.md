## 8. 实现口径

| 项 | 实现 |
|---|---|
| 类名 | 沿用 `.c-byte` / `.c-byte__x` / `.is-x`，样式不 scoped，保证 `useMatrixWriter` 写 `className` 能命中 |
| 边框 | 只改 `border-color`；宽度由 `--rule-region-w` 控制 |
| 单值属性 | `data-bd` / `data-txr` 预留，调试页已验证 |
| 角位 | 2 个 `__corner`，本页使用 `tr`（changed）/ `br`（error）/ `bl`（done） |
| downstream | 边框走 `--st-downstream-border` 一层令牌，演示态自动不降 |
| error 隔离 | 所有 error 特征选择器带 `:not(.is-downstream)` |
| done 缺口 | 纸色方块压边，不断 `border` |
| 禁止项 | 无 `!important`；叠加结果不依赖 class 书写顺序，组合态有独立规则 |
