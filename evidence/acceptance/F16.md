## 5. 实现口径

| 项 | 实现 |
|---|---|
| useSSE | `fetch + ReadableStream + AbortController`；60 行；无 EventSource |
| SSE 解析 | 移到 `utils/sse.ts`，支持 `meta/token/done/error` 与 `\r\n\r\n` |
| active 计数 | `window.__sse.active`，start 增、finally 减、abort 清零 |
| 请求体 | 只传 `trace_id / step_index / question` |
| 数值高亮 | 答案按 hex/十进制切段，数值渲染成按钮；点击显示「引用本步数值：…」 |
| aria-live | 流式正文不在 live region；`done` 后一次性写入 `.sr-only[aria-live]` |
| 切步 | watch `stepIndex`，流式中 abort；旧答案折叠一行；不自动重发 |
| 卸载 | `onScopeDispose` abort + `activeChannel='idle'` |
| 通道互斥 | `useUiStore.activeChannel='tutor'`；MatrixStage 跳过动效；播放器暂停 |
| 后端接入 | WorkbenchView `onMounted` POST `/api/aes/trace` 注册 trace_id；Vite dev 代理 `/api` → `127.0.0.1:8000` |

## 7. 已知边界

| 项 | 说明 |
|---|---|
| E 区折叠/演示态 | `<1120px` 与 `[data-mode="present"]` 下 TutorPanel 隐藏，只保留 48px 竖条；F15 的 A 区演示开关仍可用 |
