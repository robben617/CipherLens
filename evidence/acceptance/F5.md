## 2. 单 rAF 写入

| 项 | 实测 |
|---|---|
| 初始写入 | `window.__MATRIX_BATCHES__ = [1]` |
| 连按 30 次 → 后的最后 30 次 | 全部为 `1` |
| 控制台 `[MULTI-BATCH]` | 0 条 |
| 控制台 error 总数 | 0 |

每次点击间隔 30ms，让每次写入落在独立帧；`useMatrixWriter.write()` 每次只 `batches++`，`flush()` 末尾归零。

## 6. DOM 顺序

实测 16 格的 `(row, col)`：

```text
(0,0) (1,0) (2,0) (3,0)
(0,1) (1,1) (2,1) (3,1)
(0,2) (1,2) (2,2) (3,2)
(0,3) (1,3) (2,3) (3,3)
```

即列优先：DOM 下标 === AES 字节下标。网格使用 `grid-auto-flow: column` + `grid-template-rows: repeat(4, var(--cell-size))`。

> 修复记录：首版只写了 4 列、没写 4 行，column flow 把 16 格排成 16 列（宽 1082，溢出 C 区）；补上 `grid-template-rows` 后复测为 266×266。

## 8. 实现口径

| 项 | 实现 |
|---|---|
| trace 存储 | `shallowRef`，未用 `ref()` / `reactive()` 包裹 |
| 16 格值 | 模板写死 `—`，不绑定表达式；`useMatrixWriter` 在 `onMounted` 后写入 |
| 写值通道 | 单个 rAF，一次遍历 16 格，写 `textContent` 与 `aria-label` |
| aria-label | hex + 十进制双写，例：`第 2 行第 2 列，字节 5，值 0x55，十进制 85` |
| 状态属性 | 预留 `data-bd="idle"` / `data-txr="none"`，本轮不改 |
| 角标 / 上标 / hint | 常驻 DOM，CSS 默认 `display:none`；F7 再按七态显示 |
| 行/列标签 | `c0–c3` 在上下方、`r0–r3` 在左侧，列优先视觉暗示 |
| 调试按钮 | `data-debug-next`，仅本轮验收入口；F13 会替换为 TransportBar |
