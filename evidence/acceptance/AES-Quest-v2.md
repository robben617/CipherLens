## 3. 两篇流程

| 状态 | 实测 |
|---|---|
| 加密篇初始 | 9 幕 A01–A09，phase=encrypt |
| 加密篇结局 | 结局卡「怪物解不开这只黑匣子」，显示「是否要为怪物开挂？」 |
| 点击开挂 | phase=decrypt，10 幕 D01–D10，D01「开挂与钥匙」 |
| D02 | 初始轮密钥加（第 10 轮） |
| D03–D06 | 逆行移位 → 逆字节代换 → 第 9 轮密钥加 → 逆列混合 |
| D07 | 第 8→1 轮倒放 |
| D08 | 最后一轮：逆行移位 + 逆字节代换，无逆列混合 |
| D09 | 收尾轮密钥加（第 0 轮），黑匣子打开 |
| D10 | 番外结局，最终卡「开挂之后，它解开了」，可回看加密篇/再玩一次/退出 |
| 回看加密篇 | phase 回到 encrypt，从 A01 开始 |
