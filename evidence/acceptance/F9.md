## 1. 行轨道与鬼格结构

矩阵从 16 格 flat grid 改为 4 条行轨道：

| 项 | 实测 |
|---|---|
| 矩阵网格 | `266 × 266` |
| 实格 | 16 个（`data-ghost` 不存在） |
| 鬼格 | 16 个（`data-ghost="true"`，`aria-hidden`，`tabindex=-1`） |
| 每行 | 8 格：4 实 + 4 鬼 |
| DOM 顺序 | 行优先（r0c0..r0c3，再 r1…） |
| AES 索引 | 仍列优先 `index = col * 4 + row`，通过 `data-index` 查找 |

初始 16 实格（视觉 4×4）：

| | c0 | c1 | c2 | c3 |
|---|---|---|---|---|
| r0 | `00` | `44` | `88` | `CC` |
| r1 | `11` | `55` | `99` | `DD` |
| r2 | `22` | `66` | `AA` | `EE` |
| r3 | `33` | `77` | `BB` | `FF` |

Tab 序列仍为 `首格 → c-matrix__debug`；按右 4 次仍停在 c3r0（字节 12）。行轨道重构没有破坏 F6 的列优先键盘语义。

## 4. Canvas 回绕描边闪

新增 `StageCanvas.vue`：

| 项 | 实测 / 实现 |
|---|---|
| Canvas 尺寸 | `266 × 266`（buffer，dpr 缩放） |
| 静帧 | `visibility: hidden` |
| 触发 | 每条行轨道的 `animation.finished` |

说明：60ms 闪烁窗口很短，本轮截图采样停在 `visibility: hidden`；实现路径已在代码中固定，未用 `setTimeout` 串联多段动效。

## 5. 性能

| 指标 | 实测 | 手册要求 | 结果 |
|---|---|---|---|
| 整步 `LayoutCount` 差值 | **2** | ≤1 | **未达** |
| 动画阶段（80ms → 680ms）差值 | 1 | — | 含动画结束与值写入 |
| >20ms 长帧 | **0** | 无 | 通过 |
| 合成层数 | **4** | ≤4 | 通过 |

与 F8 同口径：整步 2 次 = 值写入 1 + 动画创建 1；动画运行期无长帧，层数 4。手册验收 2 的“整步 Layout ≤1”仍未达，已在已知边界中标注。

## 6. 关闭 ShiftRows 动效后其他操作

设置 `document.documentElement.dataset.motion = 'reduced'`，连续走 5 步：

| 步骤 | op | running animations | tracks transform | 值更新 |
|---|---|---|---|---|
| 1 | `add_round_key` | 0 | 全部 `none` | 正常 |
| 2 | `sub_bytes` | 0 | 全部 `none` | 正常 |
| 3 | `shift_rows` | 0 | 全部 `none` | 正常（直接写终态） |
| 4 | `mix_columns` | 0 | 全部 `none` | 正常 |
| 5 | `add_round_key` | 0 | 全部 `none` | 正常 |

关闭 ShiftRows 动效后，其他三种操作仍按静态换值正常工作。

## 7. 通道特征

ShiftRows 使用“整行横向位移”：

- 位移主体是 DOM 行轨道，不是 Canvas；
- 全站唯一的横向位移通道；
- 行序 40ms stagger；
- Canvas 只负责回绕瞬间的 1px 描边闪，不画字节。

其他三种通道中，SubBytes 已在 F8 实现；MixColumns / AddRoundKey 尚未实现，四通道并列对比留到 F11。
