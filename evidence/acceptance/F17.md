## 5. 发送按钮 / busy 口径

修复前 `cache`、`generic` 被算作忙，完成后发送按钮永久锁死。现口径：仅 `waiting / slow / streaming`，或 `(generic|cache) && !finished` 时为忙；`onDone / onError / stop / forceState` 均写 `finished`。

| 状态 | 发送按钮 disabled | 停止按钮 | 按钮文案 |
|---|---|---|---|
| idle | false | 无 | 发送 |
| waiting | **true** | 有 | 生成中… |
| slow | **true** | 有 | 生成中… |
| streaming | **true** | 有 | 生成中… |
| done | false | 无 | 发送 |
| cache | false | 无 | 发送 |
| generic | false | 无 | 发送 |
| offline | false | 无 | 发送 |
| error | false | 无 | 发送 |
| interrupted | false | 无 | 发送 |
| collapsed | false | 无 | 发送 |

## 6. 实现口径

| 项 | 实现 |
|---|---|
| 状态机 | `phase` 单一 ref，11 个枚举值；模板 `:data-phase` 供探针/样式读取 |
| 首字阈值 | `setTimeout(3000)`，仍为 `waiting` 才进入 `slow` |
| 总阈值 | `setTimeout(20000)`，仍忙则 abort、切 `offline`、`finished=true` |
| 缓存直出 | `onMeta.cache===true` → `phase=cache`，token 逐帧拼接，无打字机定时器 |
| 通用讲解 | `onMeta.quotes_values===false` → `phase=generic`，提供「带上这一步的数据重问」 |
| 错误态 | 行内 `.tutor__error` + 重试按钮；不使用 toast |
| 中断 | `stop()` → abort + `interrupted` +「已中断」；问题保留 |
| 切步折叠 | watch `stepIndex`：有回答则折叠一行，不自动重发 |
| 离线模板 | 由 `stepBefore/stepAfter/changed/stepLabel` 生成，数值来自服务端 trace |
| 调试开关 | `?debug=tutor` 下拉 11 态；`?debug=tutor-timing` 断网计时（均仅 DEV） |

## 8. 已知边界

| 项 | 说明 |
|---|---|
| `?debug=tutor-timing` | 只跳过真实 SSE，仍走 3s/20s 定时器；用于断网复现，不替代真实网络异常测试 |
| 缓存时间 | 16.2ms 为浏览器端点击到终态；不含首次冷启动的 231.7ms |
| 通用讲解 | 后端当前 `source=local` 始终 `quotes_values=true`，`generic` 仅由调试开关与前端 meta 分支覆盖 |
| 错误态来源 | `onError` 由 fetch/HTTP/SSE 错误触发；后端目前无主动 error 帧场景，`error` 态以调试开关取证 |
| 折叠行 | 只显示首 64 字；不保留历史轮次 |
| 本地模板 | 固定句式，未接真实 LLM；文案含本步真实数值，避免「AI 暂时不可用」式空话 |
| 通道互斥 | 降级/中断/完成均 `activeChannel=idle`，不阻塞后续播放与矩阵动画 |
