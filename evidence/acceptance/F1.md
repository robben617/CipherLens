## 1. FIPS-197 锚点

| 断言 | 实测 | 结果 |
|---|---|---|
| `SBOX[0x00]` | `0x63` | 通过 |
| `SBOX[0x53]` | `0xed` | 通过 |
| `INV_SBOX[0x63]` | `0x00` | 通过 |

以上三条由测试 `matches the FIPS-197 anchors` 覆盖。

## 2. 256 项互逆

|---|---|
| 覆盖项数 | 256 |
| 失败项 | 0 |
| 测试 | `keeps S-box and inverse S-box mutually inverse` |

## 4. 实现口径

| 项 | 实现 |
|---|---|
| S 盒来源 | FIPS-197 Figure 7 原始 16×16 表，未用代码现算 |
| 逆 S 盒来源 | 由 `SBOX` 循环生成 `INV_SBOX`，未手抄第二张表 |
| 互逆断言 | 模块加载时检查 256 项，失败即抛错 |
| 数据结构 | `Uint8Array`，非 `number[]` |
| 返回值 | `subBytes` / `invSubBytes` 返回新数组，不修改入参 |
| 缓存 | 无记忆化，256 项直接查表 |
| Vue 依赖 | `engine/` 下无 `import 'vue'`，测试在 Node 环境运行 |
| 第三方依赖 | 无 |
