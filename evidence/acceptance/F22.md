## 3. 纯键盘链路与焦点序列

脚本按验收顺序逐个动作，每步记录 `document.activeElement`：

| 动作 | 实测结果 | 焦点 |
|---|---|---|
| `V` 载入向量 | step=0 | `.c-byte`（index 0） |
| `Space` 播放 | `isPlaying=true` | 仍在矩阵格 |
| `Space` 暂停 | `isPlaying=false` | 仍在矩阵格 |
| `A` 聚焦 AI | — | `TEXTAREA[aria-label="向 AI 提问"]` |
| `Enter` 发送 | `phase=streaming` | 仍在 textarea |
| `Esc` 停止生成 | `phase=interrupted` | 仍在 textarea |
| `Esc` 关批注 | 批注 true → **false** | textarea |
| `Enter` 开抽屉 | 抽屉 open，标题「字节 0 · 第 1 行第 1 列」 | `.c-drawer__close` |
| `Esc` 关抽屉 | open=false | **回到原 `.c-byte`（index 0）** |
| `End` + `[` 跳上一个标记 | step=**27** | `.c-mark[data-step="27"]` |
| `Enter` 打开标记详情 | open=true，标题「第 27 步 · 标记详情」 | `.c-drawer__close` |
| `Esc` 关标记详情 | open=false | **回到 `.c-mark[data-step="27"]`** |

结论：

| 项 | 实测 |
|---|---|
| 焦点丢失到 `body` | **0 次** |
| 焦点进入不可见区域 | **0 次** |
| 抽屉焦点陷阱 | 打开即聚焦关闭按钮；Tab 在抽屉内循环 |
| 焦点归还 | 字节抽屉 → 矩阵格；标记详情 → 标记按钮 |
| 控制台 error | **0** |

截图：`evidence/acceptance/F22-keyboard-chain.png`（45,319 B）。

## 4. 快捷键覆盖

手册 §2.5 键位表已全部接管（输入框/文本域/contenteditable 聚焦时除 `Esc` 外失效）：

| 键 | 行为 |
|---|---|
| `Space` / `←` / `→` | 播放暂停 / 上一步 / 下一步 |
| `Shift+←` / `Shift+→` | 上一轮 / 下一轮第一步 |
| `Home` / `End` | 首步 / 末步 |
| `[` / `]` | 上一个 / 下一个有标记的步，并把焦点移到该标记 |
| `Enter` | AI 输入框发送；矩阵格 / 标记打开详情 |
| `Esc` | 关闭帮助 > 关抽屉 > 中断生成 > 关批注 > 退出播放 |
| `A` / `J` / `V` / `P` / `E` / `S` / `?` | 聚焦 AI / 聚焦时间轴 / 载入向量 / 演示模式 / 导出 trace / 跳 S 盒 / 帮助浮层 |
| `D` / `F` / `G` / `1` `2` `3` | 已接管，但对应功能未实现，播报「未接入」，不假装执行 |
| `Tab` / `Shift+Tab` | 不接管，保留原生焦点顺序 |

> 透明说明：`D`（解密）、`F`（AI 栏折叠）、`G`（密钥扩展抽屉）、`1/2/3`（密钥长度切换）依赖的功能在当前仓库尚未实现，键位只做接管并明确播报“未接入”，没有伪造状态。验收链路只使用已实现的键位。

## 6. 实现口径

| 项 | 实现 |
|---|---|
| 表格视图 | 真 `<table>` + `caption` + `th scope`；直接接收 `values`，不复制 trace |
| 表格切换 | A 区按钮 `aria-pressed`，切换后焦点回到该按钮 |
| live region | `WorkbenchLayout` 内单一 `.sr-only[aria-live="polite"][data-live]`；`watch(currentStep)` 每步一次 |
| 抽屉 | `role="dialog" aria-modal="true"`，固定覆盖 E 区；打开聚焦关闭按钮；Tab 循环；Esc 关闭 |
| 焦点归还 | 打开时记录触发元素；关闭后 `nextTick` 聚焦触发元素 |
| 标记 | 每个标记一个 `<button class="c-mark" data-step>`；`[`/`]` 同时跳步 + 聚焦；Enter 打开详情 |
| Esc 优先级 | 帮助 > 抽屉 > AI 生成 > 诊断批注 > 演示模式 > 播放 |
| 输入守卫 | `input/textarea/select/contenteditable` 聚焦时除 Esc 外全部不响应 |
| 矩阵 Tab | 仍只有 1 个 `tabindex=0`，方向键 roving，未给 16 格都写 0 |
