## 7. 实现口径

| 项 | 实现 |
|---|---|
| roving 索引 | `activeIndex` 0..15，DOM 顺序即列优先 `index = col * 4 + row` |
| 上 / 下 | `index ± 1`，受 `row` 边界限制 |
| 左 / 右 | `index ∓ 4`，受 `col` 边界限制 |
| 边界 | 不环绕、不跨行；方向键始终 `preventDefault`，避免页面滚动和全局快捷键误触发 |
| 焦点移动 | `focus({ preventScroll: true })`，不滚动页面 |
| 选中态 | roving 只改 `tabindex` 和焦点，不挂 `is-selected`；选中态留给 W2 |
| 全局键 | `Space` / `ArrowLeft` / `ArrowRight` / `Home` / `End`，绑在 `window` |
| 输入框守卫 | `input` / `textarea` / `select` / `contenteditable` 或 `isContentEditable` 时全部失效 |
| 事件让位 | 矩阵 `useRovingGrid` 先 `preventDefault`，`useHotkeys` 检查 `event.defaultPrevented` 后不处理 |
