## 2. SSE 逐字流式（nginx 未缓冲）

通过 `http://127.0.0.1:8080/api/tutor/ask` 读取原始 SSE 帧：

```text
frames: meta, token × 7, done
token_arrival_ms: 0.06, 31.11, 61.57, 92.24, 123.16, 153.98, 184.47
gaps_ms:          31.05, 30.46, 30.67, 30.92, 30.82, 30.49
first_token_ms:   0.06
total_ms:         215.22
```

| 项 | 实测 |
|---|---|
| 帧序列 | `meta → token×7 → done` |
| 首 token | **0.06ms**（预算 <3000ms） |
| 总时长 | **215.22ms**（预算 <20000ms） |
| token 间隔 | 30.46–31.05ms，逐帧到达，不是一次性返回 |
| Content-Type | `text/event-stream; charset=utf-8` |
| Transfer-Encoding | `chunked` |
| Content-Encoding | **无**（/api 未 gzip） |

nginx 配置实测：

```text
20: proxy_buffering off;
22: proxy_read_timeout 60s;
23: gzip off;
```

> 没有在 nginx 层给 `/api` 开 gzip；`proxy_buffering off` 保证 token 不被攒批。

## 6. 实现口径

| 项 | 实现 |
|---|---|
| 前端构建 | `node:20-alpine` + `npm ci` + `vue-tsc && vite build` |
| 前端运行 | `nginx:1.27-alpine`，`/usr/share/nginx/html` |
| 后端 | `python:3.12-slim` + `pip install -r requirements.txt` + uvicorn |
| 反向代理 | `location /api/` → `http://backend:8000`，HTTP/1.1，`proxy_buffering off`，`proxy_read_timeout 60s`，`gzip off` |
| SPA 路由 | `try_files $uri $uri/ /index.html` |
| 数据库 | `cipherlens-data:/app/data` |
| 健康检查 | 后端查 `/api/records/summary`；前端 `wget /` |
| E2E | Playwright + 系统 Chrome；配置文件与用例入库 |

## 7. 已知边界

| 项 | 说明 |
|---|---|
| 基础镜像 | 本机镜像源返回 HTML，需先用 daocloud 拉取并回打 tag；Dockerfile 本身用标准镜像名 |
| 端口 | 前端固定 `8080:80`，不是 80；`localhost:8080` 即验收地址 |
| Playwright 依赖 | 未写入 `package.json`；验收用 `npm install --no-save` 临时安装，避免污染生产依赖 |
| SSE 证明方式 | 用原始帧到达时间戳证明逐帧，不是录屏；浏览器端另有 Playwright 流式断言 |
| Layout | 每步 Layout 2.47 为 F21 已记录未达项，本轮未修改动画/通道，不重复凑指标 |
| 多架构 | 未构建 arm64 镜像；本轮只验证本机 amd64 |
| HTTPS | 未配置证书，localhost HTTP |
| 数据卷 | 容器重启保留；`docker compose down -v` 会删除数据，属预期 |
