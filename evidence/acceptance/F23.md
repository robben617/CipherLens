## 1. URL 状态与刷新恢复

初始 URL：`/workbench?perf=1&vector=c3`（C.3 向量，56 步）。

操作：设步号 12 → 切表格视图 → 开演示模式，等待 >300ms。

| 时刻 | URL | history.length | step | table | present | stepCount |
|---|---|---|---|---|---|---|
| 操作前 | `/workbench?perf=1&vector=c3` | **2** | 0 | false | false | 56 |
| 同步后 | `/workbench?perf=1&vector=c3&step=12&view=table&present=1` | **2** | 12 | true | true | 56 |
| 刷新后 | 同上 | **2** | **12** | **true** | **true** | **56** |

结论：

| 项 | 实测 |
|---|---|
| 步号进 URL | `step=12` |
| 表格视图进 URL | `view=table` |
| 折叠/演示态进 URL | `present=1` |
| 参数（向量）保留 | `vector=c3`，刷新后仍 56 步 |
| 刷新后全部恢复 | **true**（step/table/present/vector 全命中） |
| URL 历史栈只增一条 | **history.length 2 → 2**（`router.replace`，未 push） |
| 节流 | 300ms（`setTimeout`，最后一次变更后同步） |

## 4. 实现口径

| 项 | 实现 |
|---|---|
| 同步方式 | `router.replace({ query })`，不使用 push |
| 节流 | 300ms；`watch` step/table/present 后合并最后一次变更 |
| 同步字段 | `step`（>0 时写）、`view=table`、`present=1`；保留 `vector`、`debug`、`byte` 等已有 query |
| 初始恢复 | `tableView = route.query.view==='table'`、`presentMode = route.query.present==='1'`；步号沿用既有 `?step` 初始化 |
| 演示态 | `WorkbenchLayout` 不再自持状态，改为 `present` prop + `togglePresent` emit；`WorkbenchView` 统一写 `dataset.mode` |
| 错误边界 | `onErrorCaptured` 捕获子树错误，记录可读 message，返回 false 阻止继续冒泡 |
| 重置 | 清除 `debug=crash`、step/view/present，暂停播放并回到第 0 步 |
| 离线提示 | trace 请求非 2xx / 无 `trace_id` / 异常时置 `offlineMode=true`；矩阵始终用本地 trace 渲染 |

## 6. 已知边界

| 项 | 说明 |
|---|---|
| “折叠态”口径 | 本轮以演示模式 `present=1`（E 区折叠/放大态）作为折叠态进 URL；AI 栏折叠 `F` 仍未实现，未编码 `ai=` |
| URL 范围 | 只同步工作台；练习页明文/密钥、记录页筛选未进 URL |
| 离线判定 | preview 无代理时必然进入离线态；不是网络质量检测，也没有重试按钮 |
| 错误边界范围 | 只包裹工作台内容；顶栏/其他路由未做全局错误边界 |
| `?debug=crash` | 人为抛错验收设施，仅 DEV/preview 演示用；生产不主动暴露入口 |
| 控制台 error | 边界测试产生 1 条预期错误；正常路径无 error |
| 历史栈 | 初始 `history.length=2` 来自 about:blank → 页面导航；同步前后均为 2，证明未新增条目 |
