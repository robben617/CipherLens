# CipherLens · 初学者学习路径与文案缺口 v1.0

> 视角：一个刚学完「密码学导论第一章」、分得清明文和密文、但没手算过 AES 的本科生。
> 目标：用这个 Web 应用从「完全不懂」走到「能给别人讲清 AES 一轮在干什么」。
> 日期：2026-11-10　配套：`CipherLens-分功能改造设计方案-v1.0.md`

---

## §0 结论

现在这套系统**能"展示"，不能"教会"**。差距不在功能数量，在三个地方：

1. **三座桥没搭**：单步 → 一轮、看懂 → 会做、会做 → 讲得出。
2. **一层入口没分**：完全不懂的人和只想复习某一步的人，走的是同一条路。
3. **十三个位置的文字是空的**：该解释的地方只有数字，该鼓励的地方没有话。

一句话：**它把 AES 摊开了，但没有牵着人走过去。**

## §2 三座桥

### 2.1 桥一：单步 → 一轮

**现状**：用户能看到第 7 步变了 4 格，但没有人告诉他「这一轮 4 步合起来干了什么」。

**缺的内容**：每轮第 4 步之后的一张小结卡（浮层，不占 41 步序列，可勾选「不再提示」）。

> **第 2 轮结束**
> 这一轮发生了三件事：
> ① 16 个字节全部被替换了一次（这一步叫**混淆**，让输入和输出的关系变得非线性）；
> ② 每列的 4 个字节现在来自 4 个不同位置（这一步叫**扩散**，让一个字节的影响摊到更多格）；
> ③ 又叠了一层只有密钥持有者知道的字节（**轮密钥加**）。
> 下一轮重复同样的四步，只是密钥换了——这就是 AES 的全部节奏。

**为什么必须有**：没有这一句，用户看到的是 41 个孤立动画；有了这一句，41 步变成「10 次同样的循环」。这是从「看热闹」到「看懂结构」的分水岭。

### 2.2 桥二：看懂 → 会做

**现状**：练习页第一题就是「填写 32 位十六进制完整密文」。这是整门课的期末题，不是第一题。

**缺的内容**：四级台阶（详见 §5）。学习者需要先「认得出」，再「填一格」，再「填一轮」，最后才是「填全部」。

**为什么必须有**：现在从「看懂」到「做对」中间隔着一整轮手算，初学者 100% 会卡住，然后关掉页面。

### 2.3 桥三：会做 → 讲得出

**现状**：走完 41 步，页面没有任何收束。用户不知道「这算学完了吗」。

**缺的三件事**：
1. **雪崩实验**：把明文改 1 位，密文变一半。这是「理解扩散」的最高点，也是答辩时最能打的一分钟。
2. **完成页**：41 步走完给一句总结 + 三个去处（再看一遍 / 去做题 / 复制分享链接）。
3. **速查卡**：一页 A4，四步示意 + S 盒 + 41 步表，能打印、能带走。

### ⑥ 单步解说（四件套，现在只有一句标签）

每个操作都要有「人话 / 类比 / 数学 / 常见误解」四层，默认只显示前两层，后两层可展开。

**字节代换 SubBytes**

```
人话：每个字节查一次表，换成一个新字节。256 个输入对应 256 个不同输出，不会撞车。
类比：像 256 个人一一换座位，谁换到哪张椅子是固定的，事后能查回来。
数学：先求这个字节在 GF(2⁸) 里的乘法逆元，再做一次仿射变换，最后异或 0x63。
误解：它不提供保密性。没有密钥参与，任何人拿到 S 盒都能反查——它负责的是「非线性」。
```

**行移位 ShiftRows**

```
人话：第 1 行不动，第 2、3、4 行分别左移 1、2、3 格。
类比：四排人向左错开站，原来同一列的四个熟人，被拆到了四列。
数学：out[c][r] = in[(c + r) mod 4][r]。
误解：不是为了「打乱顺序」好看，而是为了让下一步的列混合能跨列混合——这是扩散的来源。
```

**列混合 MixColumns**

```
人话：每一列 4 个字节，各自乘上系数再相加，一整列一起变。
类比：4 个人凑钱，每人按不同比例出，凑出来的数谁都单独改不了。
数学：在 GF(2⁸) 上乘固定矩阵 [[2,3,1,1],[1,2,3,1],[1,1,2,3],[3,1,1,2]]。
误解：这里的乘不是普通乘法，超过 0xFF 要模一个多项式；所以手算容易错，工具的价值就在这。
```

**轮密钥加 AddRoundKey**

```
人话：把当前 16 个字节和这一轮的 16 个密钥字节，逐个异或。
类比：盖一层只有你知道的印章；盖两次能擦掉，因为异或可逆。
数学：state ⊕ round_key。
误解：这是四步里唯一真正用到密钥的一步。另外三步就算全公开，没有密钥也还原不了。
```

## §4 设计缺口 7 项

### 4.1 全局进度地图

**现状**：只有 `7 / 41` 这个数字。
**要做的**：41 格横条，按「初始 + 10 轮」分成 11 段，当前步高亮，hover 显示「第 3 轮 列混合」。点击可跳。
**为什么**：数字只告诉你「还剩多少」，地图告诉你「现在在结构的哪个位置」。这是形成心智模型的关键。

### 4.2 专注模式（视线引导）

**现状**：五个区域等权重，不知道先看哪。
**要做的**：一个开关。打开后，与当前步无关的格子降到 30% 不透明度（不是变灰，避免误读成「未变」），当前步涉及的列/行加 2px 范围括。
**默认**：引导期（前 3 次访问）默认开，之后记住选择。

### 4.3 一轮小结卡

见 §2.1。**插入时机**：每轮第 4 步（轮密钥加）之后，浮层 320px，不阻断键盘。

### 4.4 雪崩实验

**现状**：完全没有。
**要做的**：工作台加一个「改 1 位看看」按钮。复制当前明文，翻转第 0 字节的最低位，并排显示两条 trace 的终态，统计：

```
改了 1 位（0x00 → 0x01）
密文 128 位里，有 63 位变了（49%）
16 个字节里，16 个都变了
```

**为什么最重要**：这是唯一一个能让初学者「哇」一下的实验，也是「扩散」这个概念最有力的证据。答辩时 30 秒能讲完。

### 4.5 分层入口

**现状**：所有人从 `/workbench` 第一步开始。
**要做的**：首页三个入口，不是两个：

- 我完全不懂 → 引导模式（3 关 + 慢速）
- 我看过一次，想自己试 → 工作台默认
- 我知道 AES，只想复习某一步 → 直接跳（四步卡带 `?step=`）

### 4.6 完成页

**触发**：走到第 41 步（末步）后，底部浮出，不遮挡矩阵。

```
41 步走完。

0011 2233 … eeff  →  69c4 e0d8 … c55a

回头看：真正让 AES 难破的不是某一步有多复杂，而是这四步重复了 10 轮。
每一步只改一点点，叠 10 次，输入改 1 位，输出会变一半。

[ 再走一遍 ]  [ 去做一道题 ]  [ 复制这个链接 ]
```

### 4.7 速查卡

**形态**：`/cheatsheet`，A4 竖版，可打印。
**内容**：四步示意（一页上半）+ S 盒 16×16（下半）+ 轮常数表 + 41 步对照表。
**为什么**：手算练习时反复切页面会打断思路；打印出来贴在桌上，是「学会」到「熟练」之间最实用的东西。

## §5 练习的四级梯度

| 级别 | 题型 | 示例题干 | 判分方式 |
|---|---|---|---|
| L1 认一认 | 单选 | 「哪一步会把 1 个字节的变化扩散到整列？」A 字节代换 B 行移位 C 列混合 D 轮密钥加 | 后端比对 `answer_index` |
| L2 填一格 | 单字节 | 「状态中某字节为 0x3F，经过字节代换后是 ___」 | 后端 `build_trace` 取对应步 |
| L3 填一轮 | 16 字节 | 「第 1 轮结束后的状态是 ___」 | 后端取 `steps[4].state_after` |
| L4 填全部 | 32 字符 | 现有题型 | 现有判分 |

**实现约束**（红线）：四级题都走 `/api/quiz/submit`，新增 `item_type` 字段；**前端不得复算答案**。

**渐进解锁**：L2 正确 2 次后才推荐 L3，L3 正确 1 次后推荐 L4。不强制，只排序。

## §6 术语与读法

### 6.1 必讲术语（12 条，**口径已统一，见下方说明**）

> **条数收敛过程**：本节原列 14 条、改造方案原列 10 条、术语专题原列 12 条，三处不一致。现统一为 **12 条**：剔除 `字节` `列` 两个日常词（不需要解释），把 `GF(2⁸)` 与 `异或` 合并为一条（异或就是 GF(2⁸) 的加法，拆开讲反而绕），`Rcon` `分组模式` 降为 L3 尾注、不进主表。

| 级 | 术语 | 一句话 | 常见误解（必须有） |
|---|---|---|---|
| L1 | 状态矩阵 state | 当前这 16 个字节，按**列**排成的 4×4 格 | 不是「按行」读，第 1 列是前 4 个字节 |
| L1 | 轮 round | 四步走一遍叫一轮，AES-128 共 10 轮 | 最后一轮只有三步，没有列混合 |
| L1 | 字节代换 SubBytes | 每个字节去 **S 盒**里查表，换成表里对应的值 | 不是随便换个值，是**查一张 256 项固定表** |
| L1 | 行移位 ShiftRows | 第 r 行**循环左移 r 个字节** | 不是「随便挪」，位移量由行号决定 |
| L1 | 列混合 MixColumns | 每列 4 字节乘一个固定矩阵，1 字节变化传到整列 | **顺序完全不变，值全变了**——不是打乱顺序 |
| L1 | 轮密钥加 AddRoundKey | 16 字节和本轮密钥**按位异或** | 不是算术加法，没有进位 |
| L1 | S 盒 S-box | 256 个字节的固定替换表，人人算出同一个结果 | 不是随机替换，表是算出来的（求逆 + 仿射） |
| L1 | 密钥扩展 KeyExpansion | 把 16 字节原始密钥推成 11 组轮密钥 | 不是简单重复密钥，每轮值都不同 |
| L1 | 轮密钥 round key | 每一轮异或用的那 16 个字节 | 不是「原始密钥」，是扩展后的第 n 组 |
| L2 | 混淆 confusion | 让密文与密钥的关系变复杂（SubBytes 负责） | 混淆 ≠ 加密，它只是「看不出规律」 |
| L2 | 扩散 diffusion | 让 1 位变化影响很多位（ShiftRows + MixColumns 负责） | 扩散不是「打散」，是**传播影响** |
| L2 | GF(2⁸) 与异或 | 字节做运算的「数域」，**加法就是异或**：相同得 0，不同得 1 | 不是普通整数加减，没有进位 |

**L3 尾注（只在用到处给一句话，不进主表、不做卡片）**：`轮常数 Rcon`（密钥扩展里每轮异或的固定常数）、`分组模式`（真实系统如何处理超过 16 字节，本工具不涉及）、`逆 S 盒`（解密时用的反查表）、`填充 padding`。

**呈现方式已改**：首次出现**就地展开三行卡**（做什么 / 类比 / 常见误解），之后收为虚线下划线，hover/Tab 回看。**不再以 hover 为主**——初学者不会去 hover 一个自己不认识的词，他不知道该查，直接滑过去，然后卡在后面某一步。实现见改造方案 F04。

### 6.2 读法（三句话，必须出现在首次进入）

1. 16 格按**列**读，第 1 列是最前 4 个字节。
2. 灰=没动，黄=这一步改了，斜纹=参与密钥运算。
3. 41 步 = 1 次初始密钥加 + 10 轮 × 4 步，最后一轮少一个列混合。

## §8 优先级与工作量

## §9 不做什么（避免把工具做成网课）

- **不做章节锁**：不强制学完第 1 轮才能看第 2 轮。初学者需要随时往回翻。
- **不做徽章 / 积分 / 排行榜**：这是教学工具，不是背单词 App；虚假激励会稀释「看懂了」的真实快感。
- **不做长视频**：文字 + 动效已经够，视频不能搜索、不能快进到某一步。
- **不做自动出题**（AI 生成题目）：判分必须可复现，题目必须人工定稿。
- **不做移动端专门布局**：保证能看，不保证好用。
